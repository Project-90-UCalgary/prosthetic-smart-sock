# Project status

## Demonstrated

- 16-channel sensor acquisition
- ESP32-based wireless transmission
- live MATLAB visualization
- spatial sensor-response display
- channel histories and recorded-session replay
- benchtop prototype integration

## In progress

- per-sensor calibration
- repeatability and hysteresis testing
- drift and curved-surface characterization
- sampling-rate and packet-delivery measurements
- electronics miniaturization
- battery-runtime and system-cost evaluation

## Not yet claimed

- validated interface-pressure measurements
- complete socket-interface coverage
- shear-force measurement
- human-participant validation
- clinical effectiveness
- use as a diagnostic or medical device

This page deliberately separates completed prototype work from planned validation so that future documentation does not overstate the evidence.
