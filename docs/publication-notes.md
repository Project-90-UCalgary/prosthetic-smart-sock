# Publication notes

Material is added to this public repository only after it has been checked for:

- team and supervisor approval
- unpublished research or lab intellectual property
- personal contact information
- participant, clinical, or otherwise sensitive data
- third-party image and logo permissions
- accurate attribution and captions
- claims that match the available evidence

Source code, editable PCB files, manufacturing outputs, raw data, calibration records, and internal notes are private by default. Approved aggregate results or high-level diagrams may be published later.

Deleting a file from the latest Git revision does not remove it from older history. The public repository history must therefore be reviewed separately from the visible file tree.
